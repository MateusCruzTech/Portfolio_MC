BH Explorer · Plataforma de Exploração
Turística de Belo Horizonte

Site para descobrir os melhores pontos turísticos e eventos de Belo Horizonte, com filtros por categoria, mapa interativo, tabela de locais e simulador de gastos para o roteiro.

01 · Visão Geral

O que é o Projeto

BH Explorer é um site multi-página desenvolvido em HTML5, CSS3 e JavaScript puro (sem frameworks) como projeto final da disciplina de Desenvolvimento Web. A proposta é ajudar visitantes e moradores a descobrir os melhores pontos turísticos e eventos de Belo Horizonte de forma rápida e visual.

A plataforma reúne um catálogo de locais organizados por categoria (Gastronomia, Cultura, Música, Natureza, Vida Noturna, Eventos e Arte), um mapa interativo com as rotas oficiais, uma tabela consolidada de locais e um simulador de orçamento para planejar o passeio em grupo.

02 · Funcionalidades

Exploração, Mapas e Simulador de Gastos

A página Explorar lista todos os locais cadastrados, cada um com nome, região da cidade e uma breve descrição · permitindo navegação rápida por categorias como Mercado Central, Praça da Liberdade, Parque das Mangabeiras e Instituto Inhotim.

A página Mapas incorpora um mapa interativo oficial (Google My Maps) com as rotas e pontos sugeridos, facilitando a visualização geográfica do roteiro antes da visita.

Calculadora de Gastos

Uma das funcionalidades centrais é o simulador de orçamento: o usuário informa o número de pessoas do grupo, o custo estimado de alimentação e ingressos por pessoa e o valor total de transporte · e o JavaScript calcula em tempo real o custo aproximado do passeio, sem precisar recarregar a página.

Tabela de Locais e Cadastro

A Tabela de Locais consolida todos os pontos turísticos em formato tabular, útil para comparação rápida. Já a página de Cadastro permite que qualquer visitante sugira um novo local para ser mapeado na plataforma, incentivando a colaboração da comunidade.

03 · Arquitetura

Estrutura Multi-página

O projeto segue uma arquitetura de site estático multi-página, com uma página inicial e subpáginas dedicadas (/pages/explorar, /pages/mapas, /pages/tabela, /pages/calculadora, /pages/formulario), além de uma página individual para cada ponto turístico cadastrado.

O JavaScript é responsável pela interatividade da interface · como os filtros por categoria na home, o cálculo dinâmico do orçamento e o comportamento responsivo do menu mobile · mantendo toda a lógica no lado do cliente, sem depender de um backend.

Deploy

A aplicação é hospedada como site estático na Netlify, com deploy contínuo a partir do repositório no GitHub.

04 · Reflexões

O que aprendi com este projeto

Como projeto final da disciplina de Desenvolvimento Web, o BH Explorer foi minha primeira experiência construindo um site completo e multi-página do zero, sem frameworks · o que reforçou fundamentos de HTML semântico, organização de CSS em um projeto de maior escala e manipulação de DOM em JavaScript puro.

Implementar a calculadora de gastos também foi um bom exercício de lógica de front-end: capturar valores de formulário, validar entradas e atualizar a interface dinamicamente sem depender de nenhuma biblioteca externa.

05 · Créditos

Projeto Final

BH Explorer foi desenvolvido como projeto final da disciplina de Desenvolvimento Web, com conteúdo turístico sobre Belo Horizonte levantado para fins acadêmicos. O código-fonte está disponível no repositório MateusCruzTech/projetoFinalDevWeb, e o projeto está publicado em bheexplorer.netlify.app.
